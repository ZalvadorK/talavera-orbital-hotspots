# Talavera Orbital — MODIS–VIIRS hotspot harmonization (work in progress)

**NASA Space Apps Challenge 2026** · Challenge: *Harmonization of MODIS and VIIRS Hot Spots*
Team **Talavera Orbital** (Puebla, Mexico) · Local Event: Bahía Blanca, Argentina (online)

## Status
We are building this project during the hackathon (November 14–15, 2026). The code, method, validation results and web app will be published in this repository before submission.

## What it will be
A web application with a harmonized burning activity calendar for Mexico and Argentina. It combines the long MODIS record with the continuity and detail of VIIRS, so that the satellite of origin no longer drives the answer.

## Data
Active fire detections from NASA FIRMS (MODIS and VIIRS 375 m). Counts are satellite hotspot detections, not individual fires. This project is not endorsed by NASA.

## Use of SI
We use SI (AI) assistance (Claude Code) for code and analysis. The team makes the decisions. A full "Use of SI" section will be added with the project.
